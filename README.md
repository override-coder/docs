# PolyCop OpenAPI documentation

Public API documentation for PolyCop, including authentication, account provisioning, wallets, trading, and automation.

Read the documentation at https://polycopai.mintlify.site.

The OpenAPI specification is in `openapi.third-party.yaml`. All example API URLs point to the test environment.

## Preview locally

Install the Mintlify CLI with `npm install -g mint`, then run `mint dev` from this directory.

Run `mint validate` and `mint broken-links` to check the documentation.
